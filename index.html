Etiquetas de autocierre by Carlos Manzano Esclapez

Etiqueta br

Dentro de un párrafo, para partir una línea en dos.

Esta frase está en la primera línea.
Esta frase aparece en la segunda línea.

Etiqueta hr

Entre dos bloques de texto: se ve como una línea horizontal.

Este contenido está antes de la línea.

Este contenido está después de la línea.

Etiqueta img

Una imagen guardada en la carpeta del proyecto, con su atributo alt.

Etiqueta input

Un campo de texto con placeholder, o una casilla de verificación.

Etiqueta link

Va en el head. Crea un archivo styles.css, enlázalo con link y aplica algún estilo para comprobar que funciona.

Etiqueta meta

La etiqueta meta proporciona información sobre la página.
Charset indica la codificación de caracteres.
Viewport ayuda a adaptar la página a diferentes tamaños de pantalla.
Description proporciona una descripción del contenido.

Etiqueta col

Dentro de una tabla, en un colgroup. Dale una clase con color de fondo en styles.css para que se vea la columna.

Carlos Lenguaje de Marcas

Etiqueta embed

Incrusta un archivo del proyecto, por ejemplo un PDF o una imagen SVG.

Etiqueta param

La etiqueta param se utilizaba para definir parámetros dentro de un elemento object.
Actualmente está obsoleta en HTML5 y los navegadores modernos la ignoran, por eso no tiene un efecto visible.

Etiqueta source

La etiqueta source sirve para indicar el archivo multimedia que se va a reproducir.
Se puede utilizar dentro de elementos como video o audio.

Etiqueta wbr

La etiqueta wbr indica un punto donde el navegador puede hacer un salto de línea si el texto no cabe en pantalla.
