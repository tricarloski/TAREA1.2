Etiquetas de autocierre by Carlos

Etiqueta br

Sirve para hacer un salto de línea dentro de un texto.

Esta frase está en la primera línea.
Esta frase aparece en la segunda línea.

Etiqueta hr

Se muestra como una línea horizontal, representa un cambio de tema o separacion entre contenidos.

Este contenido está antes de la línea.

Este contenido está después de la línea.

Etiqueta img

Sirve para mostrar una imagen mediante el atributo src

Etiqueta input

Crea un campo de entrada para que el usuario pueda introducir o seleccionar información

Etiqueta link

Enlaza el documento HTML con un recurso externo, en este caso, una hoja de estilos CSS.

Etiqueta meta

La etiqueta meta proporciona información sobre la página.
Charset indica la codificación de caracteres.
Viewport ayuda a adaptar la página a diferentes tamaños de pantalla.
Description proporciona una descripción del contenido.

Etiqueta col

Permite aplicar características a una o varias columnas de una tabla.
(En Aules me dices que no ves el color, yo tengo color en los títulos "Nombre" y "Asignatura", lo demás me parecía poco limpio ponerle color también.)
(No se si te refieres a eso, igualmente te lo pongo como lo quieres).

Nombre Asignatura
Carlos Lenguaje de Marcas

Etiqueta embed

Sirve para incrustar contenido externo o archivos multimedia dentro de la página, en este caso un PDF.

Etiqueta param

La etiqueta param se utilizaba para definir parámetros dentro de un elemento object.
Actualmente está obsoleta en HTML5 y los navegadores modernos la ignoran, por eso no tiene un efecto visible.

Etiqueta source

La etiqueta source sirve para indicar el archivo multimedia que se va a reproducir.
Se puede utilizar dentro de elementos como video o audio.

Etiqueta wbr

La etiqueta wbr indica un punto donde el navegador puede hacer un salto de línea si el texto no cabe en pantalla.
